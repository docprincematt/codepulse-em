# How to give CodePulse EM to nurses

## Fastest (WhatsApp)

1. Send `CodePulse-EM.html` (the single file) in the ED nurses group.
2. Each nurse taps the file → Open with **Chrome**.
3. Chrome menu (⋮) → **Add to Home screen** → Add.
4. Icon appears like an app. Works after that even with poor signal.

Do **not** open it in WhatsApp’s in-app browser if you can avoid it. Chrome is required for Add to Home screen, speech, and vibration.

## Rules for shared tablets

- Training / mock codes only.
- No name, no IP number, no photo.
- Clear logs after the session (Logs → Clear all local logs).
- Official times still go on the hospital Code Blue form.

## What this is not

Not an AHA or MGH product. Not a medical device. Doses are teaching calculations — confirm on the length-based tape and Elite Mission protocol.
