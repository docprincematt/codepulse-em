# CodePulse EM

Training Code Blue recorder and chest-compression-fraction (CCF) app for nurses.

**Not an official AHA or MGH product. Not a medical device.**

## Use it

1. Download [CodePulse-EM.html](https://github.com/docprincematt/codepulse-em) from Releases or this repo.
2. Open in **Chrome** on the phone.
3. Menu → **Add to Home screen**.

See [SHARE.md](SHARE.md) for WhatsApp instructions.
